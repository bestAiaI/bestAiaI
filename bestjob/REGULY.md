# Reguły wykonawcze BestJob

## Dane

Jednostką pracy jest jeden uczestnik. Stosuj stabilne ID, przypisany adres, wersję programu i lokalny slot. Operator utrzymuje prywatny skoroszyt. Utwórz poniższe zakładki z nagłówkami, jeśli brak odpowiadających im tabel. Przy istniejącej instalacji zapisz mapowanie nazw i zachowaj dane.

| Zakładka | Kolumny lub zakres informacji |
|---|---|
| Konfiguracja | konto nadawcze, strefa IANA, folder, źródło reguł, zatwierdzone sloty, tryb próbny/aktywny |
| Osoby | ID, odbiorca, wersja, zgoda, slot, kryteria twarde, preferencje, wyjątki, źródła CV, poprzednia wysyłka, osobisty skoroszyt |
| Profil i projekty | ID osoby, kategoria, fakt, poziom potwierdzenia, źródło, data, problem, wkład, technologia, rezultat |
| ListaFirm | osoba, firma, strona kariery, status Monitoruj/Propozycja/Wstrzymane, atrakcyjność i powód, ostatnia kontrola |
| Oferty | klucz oferty, firma, rola, tryb, miejsce, płaca i jednostka, wymagania, URL, weryfikacja i data |
| Wysyłki | osoba, lokalna data, Gmail ID, temat, wariant, klucz oferty, status CV, plik, prompt CV, wybrany wariant |
| Feedback | osoba, ID wiadomości, data, oferta lub temat, fakt lub pytanie, odpowiedź, aktualizacja profilu |
| Aplikacje | osoba, oferta, data wysłania aplikacji, kierunek, typ firmy, etap, data reakcji, wynik, źródło |
| Rozwój | osoba, umiejętność, stan wiedzy, temat, dowód, źródło, następny krok |
| Quiz i rozliczenia | osoba, Gmail ID, czas wysłania, umiejętność, pytanie, opcje, klucz, termin, ID odpowiedzi, wynik, zmiana EXP i poziomu, klucz zdarzenia |

Przechowuj opcje quizu i klucz w prywatnym rejestrze operatora. Wewnętrzny dokument uwag jest opcjonalny. Kandydat odpowiada na mail. Odczytuj raz reguły, potem wiersze właściwej osoby i nieprzetworzone zmiany. Wspólne mogą być publiczne fakty o ofercie. Ocenę, CV, preferencje i historię prowadź osobno.

## Każdy przebieg

1. Ustal właściwy slot w skonfigurowanej strefie lokalnej, z uwzględnieniem zmiany czasu. Wybierz dokładnie jedną osobę. Gdy slot jest niejednoznaczny, zgłoś problem operatorowi. Przy nadrabianiu wymagaj wskazania osoby i daty raportu. Sprawdź zgodność połączonego Gmaila z kontem nadawczym przed czytaniem poczty.
2. Sprawdź dziennik oraz Gmail Wysłane po dokładnym odbiorcy, temacie i dacie raportu. Potwierdzony mail kończy wysyłkę na ten dzień. Uzupełnij brakujący log z istniejącej wiadomości. Nie uruchamiaj równoległych zadań dla jednego slotu. Przy sprzecznym statusie lub niepewnym wyniku najpierw uzgodnij zapis z Gmail.
3. Przejrzyj wszystkie nowe odpowiedzi właściwego nadawcy we wszystkich jego wątkach BestJob, również przeczytane i w starszych wątkach. Uwzględnij kolejne strony wyników i pominięte wcześniej odpowiedzi. Deduplikuj po ID wiadomości, pomiń cytaty. Zapisz datę, źródło, ustalenia, pytania i korekty przy tej osobie. Odróżnij zainteresowanie, wybór oferty, wysłaną aplikację i odbytą rozmowę. Uwagi o całym programie przekazuj operatorowi do zatwierdzenia jako regułę wspólną. Uwagi „dla mnie” aktualizują profil uczestnika.
4. Sprawdź oficjalne kariery wszystkich firm oznaczonych Monitoruj. Uzupełnij nieaktualne adresy stron. Przeszukaj też odpowiednie portale (m.in. Pracuj.pl, No Fluff Jobs, theprotocol.it, Just Join IT, LinkedIn Jobs) i firmy spoza listy. Zacznij od ofert wskazanych przez uczestnika. Gdy wynik jest pusty, rozszerz synonimy ról, kompetencje pokrewne i firmy w granicach profilu. Nową firmę dodaj jako Propozycję. Oddziel atrakcyjność pracodawcy od atrakcyjności stanowiska.
5. Otwórz konkretne ogłoszenie, potwierdź aktywność, datę sprawdzenia, lokalizację, zdalność, formę umowy, wymagania obowiązkowe i jawne widełki. Przy niedostępnej stronie oznacz wynik jako niezweryfikowany. Porównuj kwoty tylko przy zgodnych jednostkach. Usuń parametry śledzące, zachowaj parametry identyfikujące wakat. Deduplikuj po ID lub kanonicznym URL, a między portalami również po firmie, roli i lokalizacji. Sprawdź aplikacje oraz wysyłki tej osoby. Istotną zmianę wcześniejszej oferty oznacz jako aktualizację.
6. Wybierz do trzech nowych ofert. Celem jest przynajmniej jedna trafna, jeśli istnieje. Przy każdej podaj bezpośredni link, warunki, obowiązkowe wymagania, dowody dopasowania i luki. Ocenę procentową, jeśli ją podajesz, oznacz jako orientacyjną. Ofertę rozwojową oznacz osobno i respektuj twarde ograniczenia. Dla rekomendowanych pracodawców sprawdź oficjalne sprawozdania, rok, przychody, wynik netto i zmianę przychodów r/r. Podaj źródło, walutę, okres, jednostkę prawną. Porównaj z aktualnym pracodawcą uczestnika, o ile jest potwierdzony. Punkt odniesienia podaj raz. Przy brakach wpisz „brak potwierdzonych danych finansowych”.
7. Dla każdej rekomendacji wykonaj reguły CV poniżej. Zastosuj format 1.0 lub 2.0 osoby. W trybie próbnym pokaż wynik operatorowi. W aktywnym wyślij jeden raport do zatwierdzonego adresata, także przy braku ofert. Sprawdź realnego odbiorcę i załączniki bezpośrednio przed wysyłką. Jeśli nie można wysłać lub zweryfikować adresu, zgłoś przeszkodę.
8. Po potwierdzeniu przez Gmail zapisz ID wiadomości, datę i osobny wiersz na ofertę, faktyczny wariant, status CV i promptu. Przy braku ofert zapisz jeden wpis informacyjny. Aktualizuj ostatnią wysyłkę, quiz i osobisty skoroszyt według rzeczywistej treści maila. Przy błędzie zapisu po wysłaniu napraw dziennik z Gmail bez ponownej wysyłki. Aplikacje do pracodawcy wymagają osobnej decyzji uczestnika.

## CV i prompt do każdej rekomendacji

Porównaj każde wymaganie obowiązkowe z faktami w profilu. Wybierz potwierdzone projekty według kolejności problem → własny wkład → technologia → wynik. Dostosuj kolejność, terminologię, język ogłoszenia i zatwierdzoną preferencję zdjęcia. Rozróżniaj kurs, samodzielne ćwiczenie i pracę zawodową. Nie wymyślaj liczb ani umiejętności. Wygeneruj czytelny PDF, sprawdź tekst, kompletność, polskie znaki, podział stron, dane właściwego uczestnika i dostępność załącznika. Jeśli faktów wystarcza na szkic, oznacz go jako roboczy i nazwij luki. Przy niemożności załączenia podaj przyczynę; prywatny link zastępczy tylko z dostępem właściwego adresata.

W każdym raporcie z ofertą wygeneruj również samodzielny prompt do nowej rozmowy. Wpisz do niego rzeczywiste stanowisko, firmę, link, wymagania, potwierdzone fakty i konkretne pytania do uzupełnienia. Poleć stworzenie CV w języku oferty, wskazanie niewypełnionych wymagań i eksport PDF. Prompt musi działać bez dostępu do arkusza operatora. Rozmowy o pojedynczej rekrutacji nazywaj NAZWA_FIRMY-NAZWA_STANOWISKA.

## Raport 1.0

Temat „bestJob RRRRMMDD”, opcjonalnie z ustalonym dopiskiem osoby. Pierwszy raport przedstawia usługę i sposób odpowiadania. Kolejne odpowiadają także na pytania z feedbacku. Zacznij od oferty dnia, następnie do dwóch innych, CV i promptów. Gdy brak nowych ofert, napisz „Brak nowych ofert o wysokim dopasowaniu”. Podaj zakres rzeczywiście wykonanego skanu, powody odrzucenia najbliższych wyników i następny kierunek. Dołącz 2–4 konkretne wskazówki lub źródłowo potwierdzony trend. Oznacz przypomnienia. Zakończ zaproszeniem do odpowiedzi na mail.

Przy włączonej sekcji rozwoju dobierz jedno wymaganie z realnych ofert. W 150–220 słowach połącz wyjaśnienie ze znaną uczestnikowi praktyką. Dodaj dwie krótkie pary pytanie–odpowiedź, ćwiczenie na 10 minut z kryterium sprawdzenia, jedno źródło i kolejny krok do portfolio. Oznacz priorytet i oczekiwany poziom. Raz w tygodniu wskaż 1–2 najważniejsze umiejętności. Jeśli osoba używa BestKnowledge, tam zapisuj dowody wiedzy i ćwiczenia. Rekrutacje oraz feedback do ofert pozostają w BestJob. Deduplikuj tematy między programami. Wysłanie lekcji nie potwierdza jej opanowania.

## BestJob 2.0

Zachowaj wyszukiwanie, CV, finanse, izolację profili i kontrolę wysyłki z 1.0. Na sygnał operatora zastąp jeden raport zaproszeniem. Wymień umiejętności wynikające z własnych wcześniejszych odpowiedzi uczestnika. Zapytaj: „Które z tych umiejętności już masz? Podaj numery lub nazwy. Jakie inne umiejętności chcesz dopisać jako już posiadane?”. Osobno zapytaj o zgodę na przejście do 2.0. Bez historii poproś o własną listę. Do czasu zgody kontynuuj 1.0.

Po zgodzie utwórz osobny skoroszyt uczestnika. Operator edytuje, uczestnik otrzymuje dostęp do odczytu wyłącznie do własnego skoroszytu. Sprawdź uprawnienia przed podaniem linku. PostacGra zawiera EXP, rangę, klasę, progi, historię naliczeń, aktualny prompt RPG i rozszerzalną tabelę umiejętności z nagłówkami i naprzemiennym tłem. PostacZycie zawiera kontakt, ustalony URL LinkedIn, fakty, samodzielny prompt do CV roboczego, role z datą, firmą, linkiem, faktycznym wariantem i wyborem oraz osobno rozmowy z datą i etapem. W rejestrze operatora powiąż wiadomość z wariantami, wymaganiami ofert, stabilnymi ID umiejętności i odpowiedziami.

Start od 0 EXP. Rangi: 0–4 Początkujący, 5–14 Adept, 15–29 Specjalista, od 30 Mistrz. Przy 0 EXP człowiek bez klasy, dalej klasa związana z rolą uczestnika. „Znam” daje co najmniej poziom 1 bez EXP; „chcę poznać” dodaje poziom 0. Deduplikuj umiejętności i zachowuj wyższe poziomy. Brak deklaracji pozostaw niewypełniony.

Mail zacznij od „EXP łącznie | Ranga | Klasa” i linku do osobistego skoroszytu. Kartę i historię rozliczeń pokazuj w arkuszu. W mailu nie pokazuj technicznych ID. Stosuj kolejno:

1. Tylko zakwalifikowane oferty I, II, III, z CV i promptami. Przy zerze pomiń blok ofert, listę odrzuceń, raport ze skanu i pole wyboru w stopce.
2. Po faktycznym wyborze w poprzednim mailu pokaż 1–3 nowe umiejętności wymagane w wybranej ofercie i zapytaj o znane. Brak wcześniejszego wyboru objaśnij tylko w pierwszej wiadomości.
3. Nagłówek „chcesz zdobyć nową umiejętność?”. Wybierz jedną na podstawie liczby różnych wybranych ofert, w których występuje. Bez historii użyj aktualnej oferty lub potwierdzonego celu profilu i wskaż podstawę. Podaj powód, cel, proste wyjaśnienie, krótkie P/O, przykład z pracy, zadanie 10 min, kryterium sprawdzenia, źródło i pytanie o dodanie na poziomie 0.
4. Jedno pytanie rekrutacyjne z czterema opcjami a/b/c/d i jedną poprawną. Losuj spośród umiejętności na karcie, także poziomu 0. Waga = 1 + liczba różnych wybranych ofert wymagających umiejętności. Dopasuj trudność do poziomu. Gdy karta jest pusta, poproś o deklarację umiejętności i pomiń nierozgrywalny quiz wraz z jego punktacją. Klucz zapisz przed wysyłką prywatnie powiązany z przebiegiem, po wysłaniu przypisz go do Gmail ID. Nie ujawniaj klucza przed odpowiedzią.
5. Wyjaśnij punktację. Stopka „Jak odpowiadać?” obejmuje uwagi do EXP/umiejętności i nowe odbyte rozmowy (firma, data, etap), wybór I/II/III/brak spośród faktycznych opcji, zgodę na dodanie umiejętności i literę quizu. Dopuszczaj częściowe odpowiedzi i dowolną wielkość liter. Zakończ „Dzięki za feedback!”.

Rozlicz quiz po pełnych 24 godzinach od faktycznej wysyłki. Sprawdź wszystkie terminowe odpowiedzi w tym wątku. Poprawna = +1 EXP i +1 poziom danej umiejętności. Dowolna terminowa odpowiedź bez poprawnego rozwiązania = 0 zmian. Całkowity brak odpowiedzi po terminie = −1 EXP, minimum 0, bez obniżenia poziomu. Przy błędzie odczytu odłóż rozliczenie. Rozlicz Gmail ID tylko raz. Każda potwierdzona odbyta rozmowa, także odrębny etap tego samego procesu, daje +10 EXP raz, z kluczem osoba/proces/data/etap. Zaproszenie nie jest odbytą rozmową. Przy ponowieniu lub częściowym zapisie odtwórz saldo i poziomy z unikalnych zdarzeń zamiast ponownie dodawać punkty. Stare wiadomości interpretuj według opcji faktycznie wysłanych, także dawnych oznaczeń A/B/C.
